1. Liste dois requisitos funcionais.

- O sistema deve receber dados de varios equipamentos;

- O sistema deve emitir alertas para os dados recebidos dos monitores;

2. Liste dois requisitos não funcionais.

- O sistema deve operar a uma temperatura entre 20 e 30 graus;
 
- O sistema deve operar continuamente.

4. O sistema é A, B ou C? Apresente evidências do cartão.

- Sistema A. Sistema hospitalar que recebe dados de monitores de sistemas vitais em uma UTI.

5. Proponha um teste importante e explique o que ele verificaria.

- Teste de Unidade para verificar se a combinacao dos dados recebidos emitem alertas quando ha um agravamento do estado do paciente.

- Testes rigirosos, monitoramento, procedimentos de recuperacao e evidencias que os requisitos de seguranca foram atendidos.
